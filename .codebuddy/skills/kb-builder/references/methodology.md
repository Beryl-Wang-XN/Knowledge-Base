# 方法论详解 (methodology)

> 被 kb-builder 的 SKILL.md 引用。给出六步引导法每一步的**引导问题清单**与**产出模板**。
> 对话式推进：每步先给草案 → 用户确认 → 落库 → 下一步。一次不问太多问题。

---

## 步骤 0 · 锚定目标

**目的**：让知识框架服务于用户真实工作决策，而非漫无边际地博学。

**引导问题**（用选择题辅助）：
1. 你的角色/职责是什么？日常最核心的产出与决策有哪些？
2. 最希望这个知识库先补齐哪种能力？（先聚焦一个突破口）
3. 时间优先级：先短期实用，还是先长期体系，还是框架优先再补新？
4. 目前自认最欠缺、最想尽快搞懂的具体主题？

**产出**：一段「目标锚定」，务必含 **知识深度锚点**（学到多深就够）+ 按时间分层的「知识要服务的场景」表。

---

## 步骤 1 · 认知框架

**目的**：搭一张全局骨架地图，让后续每条知识都能挂靠。

**做法**：
1. 找一条**主线脊柱**（AI 用的是"一次推理请求的生命周期"）——一条能把技术/成本/商业串起来的主流程。
2. 沿脊柱拆出**模块树**（AI 是 A–G 七模块），每模块给主题词。
3. 为每模块标**深度标准**（深/中/浅 + 判断标准）与优先级。
4. 识别**核心结构化实体**（见理念 6），单列为一个模块（AI 的 G 模型档案库）。

**引导问题**：主线对不对？模块全不全？深度标注准不准？

**产出**：`framework.md`（含定位与深度锚点、脊柱、模块表、深度标准、核心实体设计、版本记录）。

---

## 步骤 2 · 分级来源

**目的**：为每模块确定可靠信息来源，确立鲜度与一手优先原则。

**做法**：联网检索各模块权威来源，按 🥇一手 / 🥈二手 / 🛠工具站 分级。
询问用户是否有内部/特定来源（对标友商、供应商、内部资料）。

**处理原则**（写入产出）：一手优先并翻译；事实回一手源核对；二手仅入门；多媒体源找文字载体，否则返回用户自学；内部源按需同步。

**产出**：`sources.md`（处理原则 + 分级图例 + 按模块来源表 + 重点组合建议 + 待补充内部源）。

---

## 步骤 3 · 学习计划 + 每日机制

**目的**：定分阶段学习路线 + 可持续的每日执行机制。

**做法**：
1. 按框架优先级分**阶段**（每阶段：主题/能力目标/主要来源/产出）。
2. 定**每日双轨机制**：🅰主轨学习（体系知识）+ 🅱副轨情报（联网拉最新，挂框架/进 inbox）。
3. 定**节奏**（如每天 20-30 分钟）与**打卡确认**（如实记录，允许跳过）。
4. 声明**能力边界**：无后台自动运行，两种实现（会话触发 / 定时自动化）。

**引导问题**：阶段顺序认可吗？每日时长与节奏？要不要定时自动化？

**产出**：`learning-plan.md` + `progress.md`（打卡表）。

---

## 步骤 4 · 数据结构 + 呈现层

**目的**：定知识"怎么存"与"怎么呈现给用户"。

**做法**：
1. **目录组织**：按框架模块分 `entries/<模块>/`；核心实体单列 `registry/`；情报进 `inbox/`。
2. **条目模板**：统一 front matter（title/module/tags/level/sources/status）+ 正文（一句话总结/关键点/**对我的意义★**/原文参考）。
3. **registry schema**：核心实体的结构化字段（分维度组），数值 `null` 表待核实。
4. **呈现层**：静态 HTML 站点（每日页可累计+历史、模块 Tab 页、quiz）；小红书文案（AI 配图）；播客口播稿。数据源唯一，一次写作多端产出。

**引导问题**：目录/模板/schema 字段是否增删？呈现方式选哪些？

**产出**：目录骨架 + `_templates/entry.md` + `registry/_schema.md` + `registry/index.md`。

---

## 步骤 5 · 生成每日 skill

**目的**：把每日流程固化为可复用、可被主动/定时触发的 skill。

**做法**：见 `references/daily-skill-template.md`。用 `init_skill.py` 初始化 `<domain>-kb-daily`，
填入每日六步流程、数据写入规范、能力边界声明、呈现层规范，用 `package_skill.py` 校验。

**产出**：`.codebuddy/skills/<domain>-kb-daily/`。
