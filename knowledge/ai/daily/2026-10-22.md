## 今日学习卡片

KV Cache 是为了不把历史 token 的 Key 和 Value 重算一遍。代价是这些向量一直占着显存，而且输出有多长事先不知道。

vLLM 论文里的量级：OPT-13B 每个 token 的 KV Cache 约 800 KB；最长 2048 token 的一条请求，最多约 1.6 GB。在 A100 40GB 上跑 13B，大约 65% 显存给权重，30% 给 KV Cache。权重装下之后，还能再接几路请求，看的是剩下的显存够不够放这些缓存。

传统系统按「可能的最大长度」预留一整块连续显存。论文测下来，真正存着 token 状态的只有 KV Cache 显存的 20.4%–38.2%。PagedAttention 把缓存切成固定块、按需分配，浪费主要留在每个请求的最后一块里，论文说实践中低于 4%。它的注意力 kernel 比 FasterTransformer 慢 20%–26%，端到端吞吐仍然更高，因为同一张卡能同时服务更多请求。

对我的意义：

- 成本模型里，并发的分母常常是 KV Cache，不是「模型能不能装进卡」。
- 「浪费从六到八成降到 4% 以内」换来的是同一张卡的请求数，也就是每 token 成本。
- 固定 system prompt、并行采样可以共享前缀。论文里并行采样省 6.1%–30.5% 显存，束搜索省 37.6%–66.3%。这是缓存命中折扣的技术理由。

## 今天的回顾

- **DeepInfer 开源了，线上服务没有整套搬出来。** [README](https://github.com/deepseek-ai/DeepInfer) 写明许可证是 Apache 2.0，当前模型是 DeepSeek-V4.1-Flash，硬件是 NVIDIA SM100 和昇腾 950。KV cache 系统、Prefill/Decode 分离的完整交付、以及副本间负载均衡，官方写明还没开源。部署问答里 DeepSeek 自己的口径是：单集群每天 155 万亿 token，谷值定价下每 GPU 小时收入 38 美元。这是他们的线上数字，不是我方能复现的收益。见 [推理框架对比](../entries/B-inference/inference-frameworks.md)。
- **OpenShell 把智能体运行和推理路由分开管。** 2026-10-21 NVIDIA 宣布参考架构可用：Rubin 跑模型，Vera CPU 跑工具，BlueField-4 上的 Sentry 做策略执行。沙箱里走 `https://inference.local` 时，供应商凭证留在网关，不进智能体进程。新闻稿里的 30 倍、2 倍、20% 是厂商说法。见 [OpenShell](../entries/D-serving/openshell-agent-runtime.md)。
- **OpenAI 模型要进 Google Cloud，还没写成在售价。** [OpenAI 公告](https://openai.com/index/openai-models-google-cloud/)（2026-10-21）说前沿模型和 Codex 的智能体流程将进入 Model Garden，用 Marketplace 购买，GCP 承诺额度可以抵扣，一般可用在未来数周。公告没有型号清单，也没有价格。Microsoft 仍是主要云合作方。见 [云厂商格局](../entries/F-landscape/maas-cloud-vendors.md)。

## Quiz

### 1

权重已经放进 GPU 之后，单卡还能同时接多少请求，首先看什么？

- [ ] 模型参数量是否刚好等于显存容量
- [x] 剩下的显存够不够放每条请求的 KV Cache
- [ ] 输出 token 的单价

> 解析：vLLM 论文的拆分是权重大约 65%、KV Cache 大约 30%。缓存随序列变长，所以并发上限跟着缓存走。

### 2

PagedAttention 省下来的是哪一块？

- [ ] 每个 token 本来就要存的 K 和 V
- [x] 按最大长度预留连续显存造成的浪费
- [ ] 模型权重

> 解析：论文说浪费降到最后一块里，实践中低于 4%。KV Cache 该占的显存还在。它的注意力 kernel 比 FasterTransformer 慢 20%–26%。

### 3

DeepInfer 这次开源，官方 README 写明还没有放出来的是哪一项？

- [ ] Apache 2.0 许可证
- [ ] DeepSeek-V4.1-Flash 的离线推理
- [x] KV cache 系统和副本间的负载均衡

> 解析：README 把这三块列为完整在线服务所需、但本次未包含。155 万亿 token 和每 GPU 小时 38 美元是部署问答里 DeepSeek 自己的线上口径。

### 4

OpenShell 沙箱里的 `https://inference.local` 把供应商凭证放在哪里？

- [ ] 写进智能体进程的环境变量，由模型自己带去
- [x] 留在网关，转发前去掉调用方自己带的凭证
- [ ] 只允许访问 api.openai.com，不经过网关

> 解析：直接访问外部推理地址走网络策略。inference.local 由网关注入已配置的后端凭证。新闻稿里的倍数是厂商说法。
