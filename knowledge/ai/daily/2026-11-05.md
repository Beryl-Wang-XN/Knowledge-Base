## 今日学习卡片

一次生成分成两段，瓶颈相反。

**Prefill** 把整段输入的 N 个 token 一次并行算完，写出第一份 KV，并吐出第一个输出 token。token 多，矩阵乘得大，卡在 GPU 算力。它决定首 token 时间 TTFT。

**Decode** 之后每一步只算 1 个新 token，却要把全部权重和已经留下的 KV Cache 从显存里再读一遍。算得少、搬得多，卡在显存带宽。它决定每个后续 token 的时间 TPOT。整段延迟大约是 TTFT 加上 TPOT 乘以输出长度。

所以输入长、输出短的请求偏算力；输出长的请求会把 GPU 占很久。输出 token 更贵，对应的是 Decode 串行占时，不是厂商随便标的价。输入便宜、输出贵这条价差，库里已有的计费条目记过：默认档里 output 单价常常是 input 的数倍。今天不新核一家一家的牌价。

两段的优化也不一样。Prefill 看分块和 PD 分离；Decode 看投机解码、量化和更高带宽的卡。加大 batch 对 Decode 更要紧，因为多个请求可以摊薄同一次权重搬运。Prefill 已经把算力吃满，组批的收益不是同一种。

- 报价前先看请求是输入长还是输出长。两种请求吃的不是同一种 GPU 资源。
- 输出价高于输入价，先用 Decode 占时来解释，再拿具体牌价核对。
- PD 分离是把这两段拆到不同机器上。vLLM 文档把它列为特性。拆了之后，算力池和带宽池可以分开扩。

## 今天的回顾

- **Jev 不是聊天模型。** TypeSafe 在 2026-09-15 把 Jev 写成第一款 System One 模型：不生成文本，一次给出事先定好结构的概率决定。他们公布的牌价是每百万 input token $0.042，output 不加 token 费。40–200 倍、193.6 倍更快、444.6 倍更便宜，是他们自己的评测，博文也写了偏差。见 [Jev](../registry/models/jev.md)。
- **Agent Compute Engine 还没对客户一般可用。** Google Cloud 2026-10-22 写，它已经支撑 Gemini 的工作任务代理，客户预览在未来数月。空闲的 microVM 可以快照暂停。服务凭证在虚拟机外面注入。20 万智能体、每秒 500 次激活、暂停恢复低于 500 毫秒，是 Google 自己的基准。见 [Agent Compute Engine](../entries/D-serving/agent-compute-engine.md)。
- **Decisions API 只计 input。** OpenAI 2026-10-22 宣布一般可用，模型是 GPT-6 Luna。predicate、choice、score 三种有界结果。牌价是每百万 input token $0.10，缓存 input $0.01，不收 output token 费。这不改 GPT-5.6 的 $4 / $20。30 分钟和 12 小时缓存写入没有准确数据。见 [Token 计费](../entries/E-economics/token-billing.md)。
- **SGLang 的 Trainium 插件进入 beta。** LMSYS 2026-10-22 写，Trainium2 和 Trainium3 可以做推理，也可以做 RL rollout。例子是 Trainium3 上生成 Qwen3-MoE-30B-A3B 的 rollout，单台 H200 上训练。吞吐和单价这篇没有给。见 [推理框架](../entries/B-inference/inference-frameworks.md)。

## Quiz

### 1

Prefill 主要卡在哪一类资源上？

- [ ] 显存带宽。每一步都要把整个模型读一遍
- [x] GPU 算力。整段输入一次做成大矩阵乘
- [ ] 磁盘。KV Cache 先落到本地盘再读回

> 解析：N 个输入 token 并行计算，算术强度高，瓶颈是 FLOPS。显存带宽是 Decode 的瓶颈。

### 2

为什么输出 token 往往比输入 token 贵？

- [ ] 输出 token 的向量维度比输入更大，所以单价必须更高
- [ ] 厂商把输出价定为输入的固定 5 倍，和计算过程无关
- [x] Decode 每步只生成 1 个 token，却要反复搬运权重和 KV Cache，GPU 被占得更久

> 解析：这是计费差价的技术来源。具体倍数要以各家定价页为准，今天没有新核一遍牌价。

### 3

TypeSafe 博文里的 Jev，输出的是什么？

- [ ] 和普通大模型一样，一个 token 一个 token生成的文本
- [x] 事先规定好结构的概率决定，不生成字符串
- [ ] 只返回一个 0 或 1，不带概率

> 解析：2026-09-15 的官方博文把 Jev 写成 System One 模型。他们公布的 output token 不加价。加速倍数是他们自己的评测。

### 4

OpenAI Decisions API 在 2026-10-22 的公告里怎么收费？

- [ ] 和 GPT-5.6 Sol 一样，标准档 $4 / $20
- [x] 基于 GPT-6 Luna，每百万 input token $0.10，缓存 input $0.01，不收 output token 费
- [ ] 按次收费，公告没有 token 单价

> 解析：公告写明不收 output token 费。30 分钟和 12 小时的缓存写入价格，公告指向另一份定价指南，这次没有准确数据。这组价格不替换 GPT-5.6 档案。

### 5

SGLang 在 Trainium beta 的那次异构 RL 例子里，训练跑在哪里？

- [ ] 和 rollout 一起，全在 Trainium3 上
- [x] rollout 在 Trainium3 上生成，GRPO 策略在单台 H200 上用 Miles 和 Megatron 训练
- [ ] 博文给出了相对 GPU 的吞吐倍数，训练不需要 GPU

> 解析：LMSYS 2026-10-22 的博文写了这次分工，没有给吞吐或单价。beta 需要申请。
