## 是什么

2026-10-21，OpenAI 宣布与 Google Cloud 合作，把 OpenAI 的前沿模型和 Codex 的 agentic workflows 放进 Google Cloud Model Garden。官方写明这还不是已经上线的通用服务：General availability 计划在未来数周，并提供申请入口。

和渠道、采购直接相关、且出自该公告的几点：

- 客户将能通过 Model Garden 购买这些模型，交易走 Google Cloud Marketplace。已有 GCP 消费承诺的企业，可以用承诺额度支付这笔采购。
- OpenAI 模型还将进入 Google Antigravity 和 Gemini Agent。公告没有写具体上线日。
- Microsoft 仍是 OpenAI 的主要云合作方。公告没有写模型清单、API 价格或和 OpenAI 直连价的差异，这些标 **待核实**。

猜测挂靠：F（模型从哪家云、以什么采购方式卖）。价格与具体 SKU 回顾时再对 Marketplace 页面。
