## 是什么

2026-10-23，Moonshot 发布 Kimi K3.1 Pro，并同时提供高速版 Kimi K3.1 Pro Highspeed。官方博客称它是 K3.1 系列的第一个模型，是 Kimi K3 的后训练版本，定位为迄今最强的 3 万亿级开放权重模型，上下文 100 万 token。当天已在 Kimi.com、Kimi Work、Kimi Code 和 Kimi API 提供。完整权重官方写明将于 2026-11-04 前发布。Kimi Enterprise 默认关闭，管理员可打开。

价格分两条渠道，本次都打开了对应页面，不互相换算：

- 国内开放平台首页标价（人民币 / 每 1M tokens）：K3.1 Pro 输入 ¥13.00、输出 ¥68.00、缓存写入 ¥13.00、缓存命中 ¥1.30。Highspeed 输入 ¥26.00、输出 ¥136.00、缓存写入 ¥26.00、缓存命中 ¥1.30。首页写 Highspeed 速度约为 K3.1 Pro 的 3 倍；英文博客写 2–3 倍。
- OpenRouter 上 Moonshot 端点的标价（美元 / 每 1M tokens）：标准端点输入 $2.00、输出 $10.00、缓存读取 $0.20；Highspeed 端点输入 $4.00、输出 $20.00、缓存读取 $0.20。页面标注发布日为 2026-10-23。Artificial Analysis 同日文章把一方价格写成输入 $2、输出 $10、缓存命中 $0.20，并称三项都比 Kimi K3 低 33%。

国内文档写明：K3 系列上下文 1,048,576 tokens，不按上下文长度分段；缓存写入按 TTL 分 5 分钟（默认）和 1 小时两档，命中部分只收缓存命中价。1 小时档的单独写入单价，首页价格卡没有单列，待核实。激活参数量官方只写「3 万亿级」，已打开的厂商页没有给出精确总参和激活参数。Artificial Analysis 写总参 2.8T、激活 104B，回顾时再和模型卡核对。

能力只记已打开页面上的口径，两套数字不要并成一个：

- 官方博客（Claude Code harness，reasoning effort 为 max）：Terminal-Bench 4.0 为 65.7%，文中对照 GPT-6 Astra 58.2%、Claude Opus 5.5 66.4%。
- Artificial Analysis（2026-10-23）：Intelligence Index 55，比 Kimi K3（max，44）高 11 分，排在 Claude Opus 5.5（58）、Claude Sonnet 5.5（56）、Muse Wonder Full（56）之后。同文写 Terminal-Bench 4.0 为 67%，高于 Claude Sonnet 5.5 的 64%，并称权重公布后会成为开放权重最高分，与领先闭源模型的分差从 12 分收到 3 分。Cost per Task 约为 $1.98。

打开 OpenRouter 页面时，标准端点的缓存命中率显示为 96.8%，加权平均输入价显示为 $0.2561 / 1M tokens、输出价 $10.08 / 1M tokens。这是当时页面上的有效价格，不是标价。
