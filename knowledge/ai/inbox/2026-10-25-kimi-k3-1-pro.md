## 是什么

月之暗面推出 Kimi K3.1 Pro，并同时提供高速版。Kimi Code 更新日志和论坛把发布写在 2026-10-23。技术博客本次打开时没有显示日期；博客写它是 K3.1 系列的第一个模型，也是迄今最强的 3T-class 开源权重模型，上下文 100 万 token，由 K3 后训练而来，完整权重将于 2026-11-04 前发布。企业侧默认关闭，管理员需要单独打开。

过去 24 小时里对得上日期的，是国内两家 MaaS 价目：

- 火山方舟 2026 年 10 月发布表把 `kimi-k3-1-pro-261024` 标为新发布，说明面向企业级长程任务与 Agentic 编程，支持深度思考、函数调用与上下文缓存。本次打开的价格页列出 `kimi-k3.1-pro`：输入 13.00 元/百万 token，缓存命中 1.30，输出 68.00，缓存存储 0.017 元/百万 token/小时。该页没有高速版，也没有写这行价格是哪一天加上的。
- 腾讯云 TokenHub 模型价格页的最近更新时间是 2026-10-24 14:51:30。广州按量计费表里有「Kimi K3.1 Pro」，读到的数字是推理输入 13、推理输出 68、缓存命中 1.3、缓存写入-5min 13、缓存写入-1h 26，单位为元/百万 tokens。同一表还有「Kimi K3 Pro HighSpeed」：26、136、1.3、26、52。这个名称和厂商模型 ID `kimi-k3.1-pro-highspeed` 不完全一样。价格页没有更新说明，不能据此断定 14:51 这次只加了这两行。新加坡表另有一组数字，转写里没有币种标题，币种与是否同日更新标 **待核实**。

Kimi 开放平台首页（人民币 / 每百万 token）与上面两家的输入、输出、缓存命中一致：K3.1 Pro 输入 13.00、输出 68.00、缓存写入 13.00、缓存命中 1.30；高速版输入 26.00、输出 136.00、缓存写入 26.00、缓存命中 1.30。首页写高速版速度约为普速版的 3 倍，技术博客写 2–3 倍。开放平台另写：始终开启思考，`reasoning_effort` 为 low / high / max，默认 max；新用户 15 元代金券不能用于 K3.1 Pro。缓存写入的 1 小时档，首页只给了一个 13.00，没有和 TokenHub 的 26 对上，标 **待核实**。

口径不要合并。开放平台写「3 万亿级参数」，没有写激活参数。Artificial Analysis 2026-10-23 的文章写总参数 2.8T、激活 104B，Intelligence Index 为 55、当时排第 4，美元价为每百万 token 输入 2、输出 10、缓存命中 0.20；Terminal-Bench 4.0 写 67%。厂商博客的 Terminal-Bench 4.0 是 65.7%（Claude Code harness，推理强度 max）。OpenRouter 把发布日写成 2026-10-23，Moonshot 端点标价为 $2 / $10、缓存读取 $0.20，Highspeed 为 $4 / $20、缓存读取 $0.20；页上转载的 Intelligence Index 是 55.1，排第 3 / 352。上下文长度 OpenRouter 写 1,048,576。

同日工具站记录的其他 OpenRouter 标价波动，各站数字对不上，DeepSeek 官方更新日志最新仍是 2026-10-17。这次不把那些波动记成厂商调价。
