## 是什么

2026-10-26，OpenAI 发布 **GPT-6.1 Terra**。官方博客把它放在 GPT-6.1 里偏效率的一档：视觉理解、computer use 和写作一起做，面向大批量职业任务。API 模型名为 `gpt-6.1-terra`。ChatGPT Work 与 Codex 里，Plus、Pro、Enterprise、Edu 可用。系统卡增补同日发布，Preparedness 分类写的是网络安全 Critical、生物与化学 High，防护栈与 GPT-6.1 Sol、GPT-6 Astra 相同。

官方博客写明的标准 API 价：每百万 token 输入 $1、缓存输入 $0.05、输出 $5，并称标准价比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%。这篇博客正文没有写 cache write，也没有写上下文长度。

Artificial Analysis 同日文章把上一代 Terra 写成每百万输入/输出 $2 / $12，缓存输入 $0.20，cache write 现为 $1.25。OpenRouter 模型页问答同样列出标准档 cache write 为每百万 $1.25。两处一致，但都不是 OpenAI 定价页原文。

OpenRouter 同页还有两套口径：页头 Context 写 1.1M，问答写 1,050,000 token 上下文、最多 128,000 completion tokens。精确上下文长度标 **待核实**。该站还列出 Flex（输入/输出 $0.50 / $2.50，缓存读取 $0.025）、Fast（$2 / $10，缓存读取 $0.10），以及 batch 变体 `openai/gpt-6.1-terra:batch`（$0.50 / $2.50，缓存读取 $0.025，cache write $0.625）。这些是 OpenRouter 页面上的端点价，不是官方博客里的标准价。

能力数字只记这次打开过的原文，不合并成一个分数。官方博客：内部易错提示上，低推理力度错误率从 GPT-5.6 Terra 的 53.6% 降到 16.7%；最大力度降到 4.3%。Terminal-Bench 4.0 最大力度解题率 50.3%，对照 GPT-5.6 Terra 已公布的 21.5%。Artificial Analysis：最大力度的 Intelligence Index 比 GPT-5.6 Terra 高 6 分，每任务成本 $0.40 对 $1.40；同文还写最大力度比 GPT-6.1 Sol 低 4 分、比 GPT-6 Luna 高 10 分。Coding Agent Index v2.0 为 48，低于 GPT-6.1 Sol 的 54、高于 GPT-6 Luna 的 31。AA-Omniscience 上「不知道却猜」的比例从 88% 降到 38%，准确率高 2 分。各 effort 的绝对 Intelligence Index 这次没有从榜单页逐档抄，标 **待核实**。

猜测挂靠：G。价格和每任务成本是这条值得回顾的原因，但不在这里写成经济模型。
