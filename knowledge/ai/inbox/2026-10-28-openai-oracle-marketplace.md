## 是什么

2026-10-27，OpenAI 宣布扩大与 Oracle 的合作，把 Oracle 应用和数据接到 ChatGPT，并用 OpenAI 的模型与产品做一批 Oracle 新服务。和采购渠道直接相关的一点：美国的 Oracle 客户可以通过 Oracle Marketplace，用现有采购流程和符合条件的 Oracle Universal Credits，购买 OpenAI API、Codex 和 ChatGPT Work。

Oracle 正在做 Oracle AI Workspace，目标是在 ChatGPT 里接上 Oracle 应用和数据，完成已批准的业务流程。同期公布、由 OpenAI 模型支撑的产品还有：Oracle AI Security Mesh（用 OpenAI 的网络安全模型找并修漏洞）、Oracle AI SMB Bundle（ChatGPT Business、Codex，加上 Oracle 应用和周期性 OCI 额度）、Oracle App Composer（用 Codex 等工具做应用，接到已批准的 Oracle 数据与工作流，部署由 Oracle 管在 OCI 上）。

OpenAI 转述 Oracle 的用量：13 万活跃 ChatGPT 用户、超过 9.5 万活跃 Codex 用户。这是渠道里的活跃用户数，不是 API 调用量。各新产品的定价和上线时间，这篇公告没给，标 **待核实**。
