## 是什么

腾讯云大模型服务平台 TokenHub 的 Token Plan 个人版限时优惠，在 2026-10-30 出现两处官方页面截止日不一致。

国内文档《Token Plan 个人版限时优惠活动》的最近更新时间是 2026-10-30 14:25:30（北京时间）。该页把「优惠活动 1」写成 2026-10-01 00:30:00 至 2026-11-02 00:00:00（北京时间），标题下标了 Hy Token Plan。打开该页时读到的折扣（页内说明 1 元可兑换 20 积分，括号内为按此折算的参考金额，单位均为每百万 tokens）：

- Auto（`tc-code-latest`）：各档统一 11 积分（0.55 元），未命中缓存输入、输出、缓存命中都是这一档。
- Kimi K3（`kimi-k3`）：7.5 折；300 / 1500 / 30 积分（15 / 75 / 1.5 元）。
- Kimi K2.7 Code（`kimi-k2.7-code`）：8 折；104 / 432 / 20.8 积分（5.2 / 21.6 / 1.04 元）。
- GLM-5.3（`glm-5.3`、`glm-5-3`）：5.5 折；88 / 308 / 22 积分（4.4 / 15.4 / 1.1 元）。
- GLM-5.3-Flash（`glm-5.3-flash`）：7 折；11.2 / 39.2 / 3.22 积分（0.56 / 1.96 / 0.161 元）。
- Hy3（`hy3-202608`）：5 折；10 / 40 / 2.5 积分（0.5 / 2 / 0.125 元）。

同一页的「优惠活动 2」写 Hy4 preview（`hy4-preview`）5 折，时间为 2026-09-25 00:00:00 至 2026-11-02 00:00:00，适用通用 Token Plan 与 Hy Token Plan；积分价 60 / 180 / 3（3 / 9 / 0.15 元）。

同日打开的活动页仍把一组优惠的结束时间写成 2026-10-30 12:00:00（北京时间），对象写成通用 Token Plan 个人版。规则是 Auto 刊例价 6 折、Kimi K2.7 Code 8 折、Kimi K3 7.5 折、GLM-5.3 5.5 折、GLM-5.3-Flash 7 折。活动页没有给出与文档页相同的积分表。Auto 的「6 折」和文档页的「11 积分」这次没有换算成同一口径，标 **待核实**。活动 1 覆盖通用 Token Plan、Hy Token Plan，还是两边都覆盖，两页写法不一致，也标 **待核实**。截止日以控制台实际抵扣为准，不把活动页上的 10-30 12:00 或文档页上的 11-02 00:00 单独当成已经生效的决定。

这是套餐内积分抵扣价，不是按量刊例价。活动页上的按量价格不记成 10-30 的新调价。Kimi K3.1 Pro 在产品动态里的上线日是 2026-10-24，活动页的「全新上线」不另记。
