## 是什么

OpenAI API 定价页在旗舰模型价格表下方写着：区域处理（data residency）端点对 2026-03-05 及之后发布的模型加收 10%；自 2026-11-01 起，FedRAMP 端点同样加收 10%。同段还写 Priority 已在 2026-07-30 改名为 Fast mode，以及 GPT-5.6 Sol 促销价至少持续到 2026-11-21。这次只把 FedRAMP 这句当作窗口内的价格变化。

API changelog 在 2026-10-31 和 2026-11-01 没有对应条目。最新一条是 2026-10-30 的 GPT-6 Rosalind，不并进这条。定价页没有写明这 10% 是否与区域处理的 10% 叠加，也没有写适用模型范围是否覆盖全部 FedRAMP 端点。这两点标待核实。这句话何时第一次出现在定价页上，本次没有查到变更记录，也标待核实。

猜测挂靠：E（价格）。价格变化，`business: true`。
