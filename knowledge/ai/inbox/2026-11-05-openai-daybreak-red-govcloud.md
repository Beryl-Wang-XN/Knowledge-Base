## 是什么

OpenAI 新闻室 2026-11-04 的帖：在 Daybreak 模型已经能通过 Amazon Bedrock 使用的基础上，获批客户现在可以在 AWS GovCloud（US-East）经 Daybreak Red 使用 GPT-5.6 Cyber。帖子把它描述成面向已授权漏洞研究、漏洞验证和安全测试的网络安全模型渠道。

接入要单独的 OpenAI Daybreak Red 批准，再加上 AWS 侧开通。Daybreak Red 批准不会自动打开 AWS 上的模型权限。帖子写明：Bedrock 上的 Daybreak Red，推理数据不用于训练模型，客户也不必把 Daybreak Red 数据分享给 OpenAI。

这篇帖没有新的模型规格或标价。价格标 **待核实**。
