## 是什么

腾讯云 TokenHub 模型列表、模型价格和国际站 Hy API Guide 的最近更新时间都是 2026-11-04。模型列表新增调用参数 `hy4`：深度思考（保留式思考）、结构化输出、Function Calling、Cache，以及图片理解；上下文 1M，最大输入 960k，最大输出 64k。同表里的 `hy4-preview` 没有图片理解。国际站把 `hy4` 写成相对 Hy4 Preview 的正式版，并写明第一次加入视觉理解；协议兼容 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages。

广州后付费目录价（元/百万 tokens）：`hy4` 与 `hy4-preview` 都是推理输入 6、推理输出 18、缓存命中 0.3。价格页注记只点名 Hy4：自该说明发布之日起至北京时间 2026-12-31 23:59:59，调用费按目录价的 50% 结算，到期恢复目录价。注记没有把这档 50% 写到 preview 上。

Token Plan 个人版页面同日更新。优惠活动 1：北京时间 2026-11-04 至 2026-11-17 12:00:00，通用 Token Plan 与 Hy Token Plan 调用 `hy4` 为 2.5 折，未命中缓存输入 30 积分（1.5 元）、输出 90 积分（4.5 元）、命中缓存输入 1.5 积分（0.075 元），均按每百万 tokens。优惠活动 4：北京时间 2026-11-04 00:30:00 至 2026-11-30 12:00:00，`hy4-preview` 为 5.5 折起，对应 96 积分（4.8 元）、198 积分（9.9 元）、3.9 积分（0.195 元）。往期活动里，preview 的 5 折写到北京时间 2026-11-04 00:30:00 截止。

OpenRouter 模型页把 `tencent/hy4` 的发布日写成 2026-11-04，上下文 1,048,576，并显示 50% off。抓取时折后标价是输入 $0.417、输出 $1.251 / 百万 tokens，页面上同时给出的折前数字是 $0.834 与 $2.501，缓存读取是 $0.042 折到 $0.021。这是该页当时的美元标价，不是用人民币目录价换算的。页上的延迟、吞吐和有效成交价是实时数，不抄进这条。

社区稿里的参数量、Computer Use 和内部评测分数，没有在上述官方文档里对上，标 **待核实**。
