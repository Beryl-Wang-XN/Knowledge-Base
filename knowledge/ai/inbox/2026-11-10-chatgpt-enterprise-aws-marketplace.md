## 是什么

2026-11-09，OpenAI 新闻室写，ChatGPT Enterprise 可以通过 AWS Marketplace 购买。组织用现有的 AWS 采购和账单关系发现、购买和管理，符合条件的支出可以计入 AWS 承诺消费。

新闻室写，Marketplace 上的产品与直接向 OpenAI 购买的是同一套模型、功能和发布节奏，包含 ChatGPT、ChatGPT Work、Codex 和 dots。它与 Amazon Bedrock 上的 OpenAI 模型并列：Bedrock 用来做应用和智能体，ChatGPT Enterprise 给业务团队日常使用。符合条件的客户也可以经 AWS Marketplace 使用 ChatGPT for Healthcare 和 ChatGPT for Financial Services。

这篇没有新的 API 标价，也没有新的模型名。
