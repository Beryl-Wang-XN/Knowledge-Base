## 是什么

2026-11-10，Claude 产品更新列出同一组知识工作功能。Claude Whiteboards 和 Claude Sheets 以 beta 推出，所有付费方案可用。Claude Dashboards 改名为 Claude Data，并改为一般可用。认证查询和实时分享仍是 beta。

Sheets 是 Claude 和团队一起编辑的表格，可以有多个标签页、公式、格式和下拉框，也能导出 .xlsx 或 CSV。Whiteboards 是共享白板，结束后可以变成文档或幻灯片，或送到 Lucid、Miro、Vani by Zoho。Data 连接数仓或 CRM，数据团队可以认证指标；实时分享让没有连接器权限的同事看到已批准查询的结果。原文点名的 Data 伙伴包括 Amplitude、Mixpanel、Omni、PostHog 和 Sigma。

管理员默认开关：Team 方案这三项默认打开。Enterprise 方案里，Whiteboards 和 Sheets 默认关闭；Claude Data 从 2026-11-19 起默认打开。可以在 Organization settings > Artifacts 里改。

同一天，交互式连接器在支持的情况下可以在对话旁边或全屏打开完整应用。产品文写到 Adobe、Atlassian、Box、Notion。另一篇写，Salesforce、NetSuite、Workday 的插件带内置技能，其中 Salesforce 和 Workday 标成 beta。符合条件的 Team 和 Enterprise 上，Claude auto-connect 进入 beta：Notion、Atlassian、Dropbox 这类应用由管理员接一次，成员第一次使用时再连上。Claude Meetings 写的是即将推出，这次还没有上线。

没有新的 API 模型，也没有 token 标价。平台发布说明没有新的 2026-11-10 节。
