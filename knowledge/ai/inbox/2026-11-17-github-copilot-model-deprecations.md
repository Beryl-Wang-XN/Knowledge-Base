## 是什么

GitHub Changelog 在 2026-11-16 写明，当天起在大多数 GitHub Copilot 体验里停用三款模型，范围包括 Copilot Chat、行内编辑、ask 和 agent 模式，以及代码补全。表上是：Claude Opus 4.8，替代建议 Claude Opus 5.5；Claude Opus 5，替代建议 Claude Opus 5.5；GPT-5.6 Terra，替代建议 GPT-6.1 Sol 或 GPT-6 Luna。停用日期都写 2026-11-16。帖子写这些停用是 2026-10-15 宣布的，生效日落在这次窗口里。

例外：Claude Opus 4.8 对按年付费的个人 GitHub Copilot 订阅者仍然可用。Claude Opus 5 从模型选择器里移除，但已有授权仍可把它用于运行时的拒绝回退。企业已有的模型策略继续生效。默认开启时，Copilot Enterprise 和 Copilot Business 会自动打开建议的替代模型，除非管理员关了全局默认或单独关掉该模型。

猜测挂靠：友商渠道里的模型下架在 F。这是供应商可用型号的变化，`business: true`。
