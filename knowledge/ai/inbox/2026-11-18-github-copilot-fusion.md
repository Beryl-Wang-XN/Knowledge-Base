## 是什么

GitHub Changelog 在 2026-11-17 更新 Copilot Fusion。可以选择它的表面新增 github.com、Visual Studio，以及 iOS 和 Android 上的 GitHub Mobile beta。正式版 GitHub Mobile 写成即将支持。用户选努力程度，由 Fusion 选择并协调模型。

这次加入的模型：Claude Sonnet 5.5 进入 Fusion Max，GPT-6.1 Terra 进入 Fusion High，MAI-Code-2 进入 Fusion Standard。MAI-Code-2 本身另记。

同一篇写，Fusion 出现在 Stanford、Harbor 和 Laude Institute 托管的 Terminal-Bench 4.1 公开榜上。Changelog 给出的数字：Fusion Max 解决率 71.2%，比它称为领先的 Opus 5.5 和 Fable 5.2 高 5.4 个百分点；成本比 Fable 5.2 低 88%，比 Opus 5.5 低 57%。这是 changelog 自己的对照，不是另开的价格页。

猜测挂靠：友商的模型路由产品在 F。这是可用型号和表面的变化，`business: true`。
