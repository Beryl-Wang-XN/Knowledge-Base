## 是什么

GitHub Changelog 在 2026-11-17 写，GPT-6.2 Astra 与 GPT-6.2 Sol 在 GitHub Copilot 一般可用。订阅范围是 Copilot Pro+、Max、Business 和 Enterprise。模型选择器列出的表面：Visual Studio Code、Visual Studio、Copilot CLI、GitHub Copilot coding agent、GitHub Copilot app、github.com、iOS 与 Android 上的 GitHub Mobile、JetBrains、Xcode、Eclipse。铺开会逐步进行。
