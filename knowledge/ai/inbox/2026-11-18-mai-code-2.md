## 是什么

GitHub Changelog 在 2026-11-17 写，MAI Code 2 与 MAI Code 2 Flash 进入 GitHub Copilot。Code 2 面向较重的智能体编码；Flash 面向日常、成本更低的编码。两款都按量计费。Copilot 价格页这次没有打开，单价标 **待核实**。

订阅：MAI Code 2 是 Copilot Pro、Pro+、Max、Business、Enterprise。MAI Code 2 Flash 再加上 Free 和 Student。两款都要求符合条件的年付订阅。表面包括 Visual Studio Code、Visual Studio、Copilot CLI、GitHub Copilot cloud agent、GitHub Copilot app、github.com、GitHub Mobile、JetBrains、Xcode、Eclipse。Business 和 Enterprise 的默认启用规则与其他新模型相同：未关全局默认、也未单独禁用时自动打开。

同一天的 Foundry 博客写，两款当天可以在 GitHub 里试；Code-2-Flash 另有 Foundry 的限量预览。博客没有写参数量或 Foundry 单价，标 **待核实**。博客里的其他目录变化另记。
