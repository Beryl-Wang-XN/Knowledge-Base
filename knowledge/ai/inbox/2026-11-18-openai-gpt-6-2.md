## 是什么

OpenAI 新闻室与 API changelog 都把 GPT-6.2 Astra、GPT-6.2 Sol 写在 2026-11-17。调用 ID 是 `gpt-6.2-astra` 和 `gpt-6.2-sol`。两款都支持 Responses 和 Chat Completions。changelog 写工具调用必须走 Responses。两份模型页都写，把 reasoning effort 设成 `none` 会被拒绝。

新闻室写，即日起 Plus、Pro、Enterprise、Edu 可在 ChatGPT Work 和 Codex 里用。Pro 500 对两款都能用 Ultrafast。Pro 200 这次开始能用 Ultrafast，先从 GPT-6.2 Sol 起。符合条件的 Enterprise 和 Edu 要工作区管理员打开。API 在发布时两款都有 Ultrafast。新闻室写，Daybreak 上目前仍是 Daybreak Blue 的 GPT-6 Sol、GPT-6 Astra 的 alpha，以及 Daybreak Red 的 GPT-6 Cyber；GPT-6.2 还要再接到 Daybreak。

两份模型页的规格：输入文本和图像，输出文本。上下文 1,050,000，最大输入 922,000，最大输出 128,000。知识截止，Astra 是 2026-05-18，Sol 是 2026-06-01。

标准价按每百万 token，短上下文。Astra：输入 $8，缓存输入 $0.4，缓存写入 $10，输出 $40。Sol：输入 $2，缓存输入 $0.1，缓存写入 $2.5，输出 $10。缓存写入价对应保留 30 分钟。短上下文、标准处理下，保留 12 小时的缓存写入，Astra 是 $20，Sol 是 $5。输入超过 272K token 时，输入和缓存单价加倍，输出按短上下文的 1.5 倍，并且按整次请求计算。Batch 是标准价的 50%。Fast 是同一上下文长度标准价的 2 倍。Ultrafast 到太平洋时间 2027-02-28 是标准价的 3 倍，2027-03-01 起是 6 倍。新闻室把 Astra 相对 GPT-6 Astra 写成输入和输出低 20%、缓存输入折扣 60%；绝对价以上面模型页为准。

模型页 Standard 速率表写出三档：Build 5,000 RPM / 1,000,000 TPM，Launch 10,000 / 4,000,000，Grow 15,000 / 40,000,000。

Artificial Analysis changelog 在 2026-11-17 给出 Intelligence Index：Astra Max 62、Xhigh 62、High 60、Medium 57、Low 46；Sol Max 57、Xhigh 56、High 55、Medium 53、Low 41。

同日的法律配置、后台完成窗口折扣、Bedrock 与 Copilot 渠道另记，不并进这一条。

猜测挂靠：新的模型 ID 和标价在 G。这是厂商型号和价格，`business: true`。
