## 是什么

GitHub Changelog 在 2026-11-18 写，Gemini 4 Neon 在 GitHub Copilot 一般可用，面向智能体编码、多步工具使用和知识工作。帖子转述 Google 的说法：质量接近 Gemini 4 Carbon，单任务 token 成本更低，开始响应更快，编码时更少做未被要求的修改，也更少对代码、工具或测试结果做没有依据的表述。模型本身另记，这一条只记 Copilot 渠道。

计费写的是按量计费下的供应商目录价。Copilot 的 Models and pricing 页这次没有打开，有没有加价待核实。

可用档是 Copilot Pro+、Max、Business 和 Enterprise。可选位置：Visual Studio Code、Visual Studio、Copilot CLI、coding agent、Copilot app、github.com、iOS 和 Android 的 GitHub Mobile、JetBrains、Xcode、Eclipse。铺开是逐步的。Business 和 Enterprise 管理员用模型策略管理；默认启用下，新模型会自动打开，除非管理员关掉全局默认或单独关掉这一款。

猜测挂靠：友商渠道里的模型上架在 F。这是供应商可用型号的变化，`business: true`。
