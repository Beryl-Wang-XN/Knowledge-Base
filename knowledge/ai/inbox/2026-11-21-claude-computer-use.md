## 是什么

Claude 帮助中心发布说明的日期是 2026-11-20。Computer use（beta）面向 Team 和 Enterprise：Claude 能看到用户的屏幕，并在用户允许的桌面应用里操作。它在新的 Claude 体验里可用，包括 Claude Desktop，以及打开了 Computer access 时的网页和 Claude Mobile。正在逐步向组织推出。平台发布说明这次没有新的 2026-11-20 节，最新仍是 2026-11-17 的关联计费。

设置页写它默认关闭，只在 Chat 与 Cowork 已统一的新体验里工作。桌面端是 macOS 14 及更新版本和 Windows。单独的 Cowork 任务和 Claude Code 不能用。开不了的组织包括已配置 HIPAA-ready、为 Claude Code 打开了 Zero Data Retention、使用客户管理加密密钥，以及 FERPA 或 K-12 设置的组织。管理员可以按 Enterprise 的自定义角色限制使用者，也可以用阻止列表或只允许列表限制应用。帮助中心写，电脑操作和用户应用之间没有沙箱；截图会随对话保存。两页都没有写单独的 token 或座位标价，待核实。
