# 为什么输出比输入贵

模型读完你的问题，和接着往下写，吃的不是同一种资源。

读问题叫 Prefill。整段输入一起算，卡在 GPU 算力。这一段很快，所以输入 token 便宜。

往下写叫 Decode。每多一个字，都要把模型和已经记住的内容再从显存里读一遍。字越多，卡被占得越久。所以输出 token 更贵。

报价前先看用户是贴长文求一句摘要，还是一句话要你写长文。前者吃算力，后者占着卡。
